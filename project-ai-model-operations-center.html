01. Contexte

Le problème traité.

Un fichier de modèle ne suffit pas pour disposer d'un système fiable et réutilisable.

Il faut conserver la configuration, comparer les candidats, enregistrer les artefacts, gouverner les promotions et surveiller l'évolution des données.

Problème

Des expériences difficiles à reproduire

Sans registre ni protocole commun, les résultats sont difficiles à comparer.

Solution

Un cycle MLOps contrôlé

Chaque candidat est entraîné, évalué, enregistré puis promu selon des règles explicites.

02. Objectifs

Ce que la plateforme doit accomplir.

01

02

03

Conserver expériences, métriques et artefacts.

04

Surveiller le drift

Détecter l'évolution des données observées.

07. Démonstration

Lancer la plateforme.

Uvicorn expose l'API et sa documentation interactive.

# Activer l'environnement
.venv\Scripts\Activate.ps1

# Tests
python -m pytest -q

# API
python -m uvicorn app.main:app \
  --host 127.0.0.1 \
  --port 8000 --reload

# Swagger
http://127.0.0.1:8000/docs
