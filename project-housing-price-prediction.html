01. Contexte

Le problème traité.

Estimer le prix d'un logement à partir de quelques caractéristiques de son quartier.

Le jeu de données California Housing décrit 20 640 districts de Californie : revenu médian, âge des logements, nombre de pièces, population, latitude et longitude. La cible est la valeur médiane des maisons de chaque district.

Question

Un modèle simple suffit-il ?

Une relation linéaire entre les variables et le prix capture-t-elle l'essentiel du phénomène ?

Démarche

Comparer, puis mesurer

Entraîner un modèle linéaire et une forêt aléatoire avec le même protocole, et les juger sur les mêmes métriques.

02. Objectifs

Ce que le pipeline doit accomplir.

01

Préparer les données

Séparer apprentissage et test, standardiser les variables.

02

Comparer deux modèles

Régression linéaire et Random Forest, même protocole.

03

Évaluer honnêtement

RMSE, R² sur le test et validation croisée à 5 plis.

04

Expliquer et réutiliser

Importance des variables, modèle sauvegardé pour l'inférence.

03. Les mathématiques

Ce qui se passe sous le capot.

Ce projet m'a permis d'appliquer directement l'algèbre linéaire, les statistiques et l'optimisation vues en BUT.

Standardisation

z = (x − μ) / σ

Chaque variable est centrée et réduite (StandardScaler), pour qu'aucune ne domine les autres à cause de son échelle.

Régression linéaire

ŷ = β₀ + β₁x₁ + … + β₈x₈

Les coefficients β minimisent la somme des carrés des erreurs Σ(yᵢ − ŷᵢ)² : un problème d'optimisation résolu par l'algèbre linéaire (moindres carrés).

Random Forest

ŷ = (1/200) Σ ŷₜ(x)

200 arbres de décision, chacun entraîné sur un échantillon aléatoire des données ; la moyenne de leurs prédictions réduit la variance du modèle.

Métriques

RMSE = √( (1/n) Σ(yᵢ − ŷᵢ)² ) · R² = 1 − SSres / SStot

Le RMSE mesure l'erreur moyenne dans l'unité du prix ; le R² mesure la part de la variance expliquée par le modèle.

Validation croisée

R²cv = moyenne ± écart-type sur 5 plis

Le jeu d'apprentissage est découpé en 5 parties : le modèle est entraîné 5 fois, ce qui donne une estimation plus fiable et sa dispersion.

Interprétation

importance(xⱼ) · coefficients βⱼ

Le pipeline trace l'importance des variables (forêt) ou les coefficients (régression) pour comprendre ce qui pèse sur le prix.

06. Démonstration

Lancer le pipeline.

Une commande entraîne, évalue et sauvegarde le modèle choisi.

# Installer les dépendances
pip install -r requirements.txt

# Random Forest, 20 % de test
python main.py --model rf --testsize 0.2

# Régression linéaire
python main.py --model lr
