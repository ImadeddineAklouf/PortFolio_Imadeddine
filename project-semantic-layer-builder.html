01. Contexte

Le problème traité.

Construire une couche sémantique fiable exige de réconcilier structures techniques, documentation métier, qualité et relations.

Le projet automatise ce travail à partir de fichiers structurés et de documentations. Chaque étape produit un résultat validé avant toute génération de code.

Problème

Des métadonnées dispersées

Les informations techniques et métier sont parfois incomplètes ou contradictoires.

Solution

Un pipeline validé

Les agents analysent et orchestrent, tandis que Python contrôle les décisions critiques.

02. Objectifs

Ce que le système doit accomplir.

01

Comprendre les sources

Extraire les métadonnées techniques et les définitions métier.

02

Vérifier la cohérence

Comparer les observations aux règles documentées.

03

Valider les relations

Contrôler les colonnes, l'intégrité et les cardinalités.

04

Générer du LookML

Produire vues, modèle et joins seulement après validation.

04. Fonctionnalités

Les briques principales.

Analyse de métadonnées

Types, nullabilité, unicité, exemples et clés candidates.

Documentation métier

Descriptions, règles, relations et données sensibles.

Relations

Cardinalités et cohérence des colonnes de jointure.

Modèle intermédiaire

Représentation sémantique structurée avant génération.

Validation LookML

Références, dimensions, mesures, Explores et joins.

Écriture sécurisée

Chemins contrôlés, UTF-8 et écriture atomique.
