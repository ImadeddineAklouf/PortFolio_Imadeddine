# Portfolio d'Imadeddine Aklouf

Portfolio statique en HTML, CSS et JavaScript.

## Pages

- `index.html` : accueil et liste des projets
- `project-semantic-layer-builder.html` : présentation du projet Semantic Layer Builder
- `project-ai-model-operations-center.html` : présentation du projet AI Model Operations Center

## Lancement

Depuis PowerShell :

```powershell
cd "chemin\\vers\\portfolio-imadeddine"
python -m http.server 5500
```

Puis ouvrir `http://localhost:5500`.

## Personnalisation

Remplacer `votre.email@example.com` dans `index.html` et ajouter les liens GitHub, LinkedIn ou GitLab lorsque disponibles.
